One print across several products. Ad images from the product page, one ad per image.

Print ID
One ID for the whole submit.
Print image
Print design reference.
Image positions (shared)
A row can set its own. Both empty = all images.
Paste a column of product URLs from Excel to bulk add.

Hướng dẫn điền form

Tạo quảng cáo cho 1 print trên nhiều sản phẩm, dùng ảnh có sẵn trên trang sản phẩm. Không cần tải ảnh quảng cáo lên.

Các bước
1

Điền Print ID và chọn Print image

Một Print ID cho cả lần gửi. Bấm Select để chọn ảnh bản in gốc từ máy. Cả hai đều bắt buộc.

2

Điền Image positions (shared)

Vị trí ảnh trên trang sản phẩm cần lên quảng cáo, đếm từ ảnh đầu tiên, cách nhau bằng dấu phẩy. Để trống thì lấy hết ảnh.

Ví dụ: 2, 3, 4 là ảnh thứ 2, 3 và 4.

3

Dán link vào Product URL

Mỗi dòng 1 sản phẩm trên zumbamboo.com. Ô Image positions của dòng để trống thì dùng ô chung. Bấm Add product để thêm dòng, dấu X để xóa. Dán một cột link từ Excel vào ô URL sẽ tự thêm nhiều dòng.

4

Bấm Create Ads

Chờ dòng chữ xanh báo đã gửi rồi mới đóng tab.

Ví dụ
Print ID ngt20522, Image positions (shared) 2, 3:
Dòng 1: https://zumbamboo.com/products/..., Image positions trống
Dòng 2: https://zumbamboo.com/products/..., Image positions 1, 4, 5
Kết quả: 5 quảng cáo.
Lưu ý
Số quảng cáo của mỗi sản phẩm bằng số vị trí đã điền. Để trống cả hai ô thì bằng số ảnh trên trang sản phẩm.
Lần đầu dùng trên một trình duyệt: bấm Enter ở ô Password required góc trên bên phải, nhập mật khẩu. Báo Wrong password thì bấm Change và nhập lại.
