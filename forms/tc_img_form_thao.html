Paste a Drive folder of images to auto create ads.

Hướng dẫn điền form

Tạo quảng cáo từ thư mục ảnh trên Google Drive. Mỗi ảnh thành 1 quảng cáo, mỗi lần gửi một thư mục.

Các bước
1

Đặt tên file ảnh

Dạng [PrintID-TypeID] ..., phần sau dấu ] ghi tự do. TypeID xem ở trang Type ID.

Ví dụ: [ngt20736-TPJ] 1.jpg

Tên chỉ có PrintID, chưa có TypeID (ví dụ ngt20736) là thiếu, phải thêm TypeID.

2

Dán link vào Google Drive folder url

Thư mục chỉ chứa ảnh và phải chia sẻ Anyone with the link.

3

Bấm Create Ads

Thấy "Sent successfully" là xong. Kết quả báo qua Telegram.

Ví dụ
ngt20736 turkey tên thư mục tùy ý [ngt20736-TPJ] 1.jpg [ngt20736-TPJ] 2.jpg [ngt20736-CZR] 3.jpg
Kết quả: 3 quảng cáo.
Lưu ý
Một file trong thư mục sai tên, sai TypeID hoặc PrintID chưa có trong hệ thống thì cả thư mục đó không lên quảng cáo. Telegram báo tên file cần sửa, sửa xong gửi lại thư mục.
Lần đầu dùng trên một trình duyệt: bấm Enter ở ô Password required góc trên bên phải, nhập mật khẩu. Báo Wrong password thì bấm Change và nhập lại.
